# 이누야샤 오의난무 PS2 한글패치

PS2 북미판 **Inuyasha: Feudal Combat (SLUS-21193)**용 비공식 한국어 패치입니다. 메뉴, 옵션, 스토리 대사, 미션 설명, 캐릭터·스테이지 선택, 대전 HUD, 메모리 카드 안내, 엔딩 크레딧을 한국어로 바꿨습니다. **메뉴 제목·챕터명·HUD 같은 그림 속 영어 글자**도 한글로 다시 그렸습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.0 (2026-10-31)**입니다.

[패치 다운로드](https://github.com/snake759494/inuyasha-feudal-combat-ps2-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 한글패치 **Inuyasha_Feudal_Combat_PS2_KO_v1.0.xdelta**와 와이드 패치 **SLUS-21193_64836393.pnach**(한글판용)입니다. 저장소에는 제작 소스, 번역, 검증 자료만 공개합니다. 원본 디스크 이미지와 완성된 디스크 이미지, 추출한 게임 파일, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

「Inuyasha: Feudal Combat」(일본명 『犬夜叉 奥義乱舞』)은 반다이가 2005년에 북미에서 낸 3D 대전 액션 게임입니다. 이누야샤, 카고메, 셋쇼마루 등 원작 캐릭터 14명이 2인 1조로 싸우며, 스토리·미션·대전 모드가 있습니다. 음성은 북미 애니메이션판 영어 더빙이며, 이 디스크에는 일본어 음성이 들어 있지 않습니다.

이 패치는 **PS2 북미판 SLUS-21193의 DVD 이미지(ISO)**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Inuyasha - Feudal Combat (USA).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Inuyasha_Feudal_Combat_PS2_KO_v1.0.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Inuyasha - Feudal Combat (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Inuyasha - Feudal Combat (USA).iso' '.\Inuyasha_Feudal_Combat_PS2_KO_v1.0.xdelta' '.\Inuyasha - Feudal Combat (Korean).iso'
```

해시를 자동으로 검사하는 도구도 있습니다. Python 3과 xdelta3가 필요하며, 같은 이름의 출력 파일이 이미 있으면 덮어쓰지 않습니다.

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\Inuyasha - Feudal Combat (USA).iso' --patch '.\Inuyasha_Feudal_Combat_PS2_KO_v1.0.xdelta' --output '.\Inuyasha - Feudal Combat (Korean).iso'
```

### PCSX2에서 실행

새 ISO를 여세요. 원본판의 세이브 스테이트는 불러오지 마세요(실행파일 내용이 다릅니다). 메모리 카드 세이브는 같은 게임 ID를 쓰므로 원본판 세이브를 그대로 불러올 수 있을 것으로 보지만, 직접 확인하지는 못했습니다.

## 16:9 와이드 패치 (PCSX2)

PCSX2 내장 패치 목록에는 원본 북미판용 16:9 패치(`SLUS-21193_E246AA30.pnach`, 제작 Little Giant)가 있습니다. 하지만 한글패치는 실행파일을 고치기 때문에 게임 CRC가 `E246AA30` → `64836393`으로 바뀌어 **내장 패치가 한글판에 자동으로 적용되지 않습니다.** 내장 패치가 바꾸는 명령 6개는 한글판 실행파일에도 원본 그대로 남아 있으므로, 같은 내용을 한글판 CRC로 옮긴 pnach를 함께 배포합니다. 3D 화면의 가로 시야를 넓혀 16:9 화면을 늘림 없이 채웁니다.

**한글패치 버전이 바뀌면 실행파일 CRC도 바뀔 수 있으므로, 와이드 패치는 항상 같은 릴리즈의 pnach를 쓰세요.**

| 파일 | 대상 | 게임 CRC |
| --- | --- | --- |
| `SLUS-21193_64836393.pnach` (릴리즈 첨부) | 이 한글패치 v1.0을 적용한 게임 | `64836393` |
| PCSX2 내장 `SLUS-21193_E246AA30.pnach` | 원본 북미판(영문) | `E246AA30` |

### 설치 (PCSX2 v2.x)

1. 릴리즈에서 `SLUS-21193_64836393.pnach`를 받습니다. 파일 이름을 바꾸지 마세요(PCSX2는 이름의 CRC로 게임을 찾습니다).
2. PCSX2 `patches` 폴더에 넣습니다.
   - 설치판: `문서\PCSX2\patches\`
   - 휴대용판: `pcsx2-qt.exe`가 있는 폴더의 `patches\`
   - 폴더 위치는 **설정 → 폴더**에서도 확인할 수 있습니다.
3. 게임 목록에서 한글판 ISO를 오른쪽 클릭 → **속성** → **패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다. 화면비는 패치가 자동으로 16:9로 바꿉니다(`gsaspectratio=16:9`).
5. 게임을 실행하면 화면에 "게임 패치 1개 활성화" 같은 알림이 나옵니다.

### 끄기·문제 해결

- 끄려면 4번의 체크를 해제합니다.
- 패치 탭에 항목이 보이지 않으면 파일 이름의 CRC와 게임의 CRC가 다른 것입니다. 게임을 실행한 뒤 **도구 → 로그 표시**에서 `CRC:` 줄을 확인하세요. 한글판 v1.0이면 `64836393`, 원본이면 `E246AA30`이 나와야 합니다.
- 원본(영문) 게임에는 이 pnach가 필요 없습니다. 같은 패치가 PCSX2에 이미 들어 있으니 패치 탭에서 켜기만 하면 됩니다.
- 화면이 여전히 4:3이면 **설정 → 그래픽 → 화면비**를 16:9로 바꾸세요.
- PCSX2 1.6 이하에서는 `cheats_ws` 폴더에 넣고 **와이드스크린 패치 사용**을 켜세요. 이 경우 `[Widescreen 16:9]` 줄을 지워야 할 수 있습니다.

### 알려진 한계

- 메뉴, HUD, 대화창 같은 2D 그림은 4:3 기준이라 가로로 늘어납니다.
- 부팅 화면과 오프닝 3D 장면에서 16:9 적용을 확인했습니다. 대전 중 화면 끝 사물이 잘리거나 깜빡이면 이슈로 알려 주세요.
- 실기(PS2 본체)에서는 쓸 수 없습니다.

### 번역 원칙

- 기계 번역 없이 문맥을 보고 직접 번역했습니다.
- 인명·기술명은 국내 방영판 표기를 따랐습니다(셋쇼마루, 미로쿠, 산고, 철쇄아, 풍혈, 비래골 등).
- 미션 설명의 버튼 아이콘 줄은 원문과 같은 줄·같은 위치에 오도록 공백으로 맞췄습니다.

### 번역하지 않은 것

- 음성(영어 더빙), 오프닝·로고 동영상
- "KO!", "1P/2P/COM/VS/LV" 같은 대전 게임 관용 표기
- 타이틀 로고, 제작사 로고, 저작권 표기, 크레딧 장식 문구
- 크레딧의 실존 인물·회사 이름
